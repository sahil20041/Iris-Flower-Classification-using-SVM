 Iris Flower Classification using SVM

A Machine Learning project that classifies Iris flower species using the Support Vector Machine (SVM) algorithm based on flower measurements such as sepal length, sepal width, petal length, and petal width.

Tools & Technologies
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

Workflow
* Data Loading & Exploration
* Data Visualization
* Feature Selection
* Train-Test Split
* Support Vector Machine (SVM)
* Model Evaluation

Evaluation Metrics
* Accuracy Score
* Confusion Matrix
* Classification Report

Key Learnings
